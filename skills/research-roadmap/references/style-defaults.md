# 默认模板规格（style defaults）

用户**未提供**参考图或 PPT 模板时，按本文件产出；用户提供了模板时，按
SKILL.md 的参考图协议提取三层（组织框架／视觉语法／语言风格）后**覆盖**本文件的对应项，
未覆盖项仍用本文件默认值。本文件是唯一样式权威；`layout-principles.md` 讲布局选择逻辑，
`svg-engineering.md` 讲工程实现，`ppt-export.md` 讲 PPT 导出流程，细节冲突时以本文件为准。

## SVG 默认样式

| 项 | 默认值 |
| --- | --- |
| 背景 | 纯白 |
| 阶段／结论节点 | 浅粉填充（如 #FBE9E7），同角色一致 |
| 普通任务节点 | 白底或极浅蓝（如 #EAF3FB），1px 深灰边框 |
| 方法／旁注 | 浅绿（如 #E8F5E9）；无必要不凑齐三色 |
| 文字与连线 | 深灰 #444，不使用纯黑 |
| 字体 | 中文 Microsoft YaHei / Noto Sans CJK SC（按实际安装选择），西文回退 Arial |
| 正文字号 | 目标 9–11 pt（按 16 cm 插入宽折算）；旁注 ≥ 8 pt |
| 节点形状 | 直角或 ≤4px 圆角矩形；阴影默认关闭 |
| 连线 | 实线箭头＝流程依赖；虚线＝候选／条件分支；正交布线规则见 svg-engineering.md |
| 画布 | 适配 16 cm 单页宽；高度按内容计算 |

## 可编辑 PPT 默认样式（来自实测模板学习）

| 项 | 默认值 |
| --- | --- |
| 页面 | 19.05 × 27.51 cm 纵向（标准 A4 比例）；内容放不下精简语言，不拉长页面、不缩字号 |
| 字体 | 中文宋体（SimSun）、西文与数字 Times New Roman，**全部统一 10 号**（`a:ea`／`a:latin`／`a:cs` 双字体写入） |
| 行距 | 单倍（`line_spacing=None`）；内边距上下 0.10–0.13 cm、左右 0.08 cm |
| 卡片 | 直角矩形、细黑边框（0.75–1 pt）、无圆角、**无阴影**（清除全部主题 `effectRef` 引用） |
| 用色角色 | 淡粉＝前期发现／阶段结论／核心命题；白底＝普通实验任务；淡蓝＝仅强调关键模型或因果验证；黑虚线＝候选／条件分支；不使用图例 |
| 阶段侧栏 | 左侧独立侧栏，纵向阶段名＋单侧括号，不侵入卡片区域 |
| 文案 | 动词＋名词词组短句（"鉴定…影响""评价…效能"），一至两行；无元话语 |
| 箭头 | 细箭头；相邻卡片直连，分叉用正交总线（同 SVG 布线硬规则） |

## 用户模板协议

1. 用户提供参考图（截图／论文图）或 PPT 模板时，先做**结构化学习**（PPT 模板需导出实际渲染预览，
   不只看 XML），提取：组织框架（证据形成阶段与依赖排序）、视觉语法（框形／线型／用色角色／留白）、
   语言风格（方框措辞模式）。
2. 只迁移这三层；**不复制**节点数量、位置、具体研究内容、已发表论文图件；页面尺寸仍按
   "内容放不下精简语言"规则取舍，不机械套用模板窄页。
3. 重大重构或风格迁移前，先把现有交付物复制到 `archive/`（带时间戳），新版本另存新文件名；
   绝不覆盖用户文件与历史版本。

## 模型能力要求

- **视觉能力（必需）**：验收门要求实际查看渲染图（PNG／PowerPoint 预览）。已知表现良好的模型：
  GPT-5.6-sol／High 等带视觉能力的型号；**要求的是能力，不绑定型号**。纯文本模型无法通过
  验收门，只能交付标注"未完成视觉验收"的 SVG 并如实说明。
- **长文本阅读（必需）**：毕业论文／基金申请书体量的材料解析。
- **Python 3（可选）**：运行 `scripts/check_graph.py` 与 PPT 生成脚本；缺失时按 SKILL.md 的
  回退处理并如实报告。
