# 论文模式 — 从论文到可调用能力 (paper mode)

## 何时进入论文模式

源材料符合以下任一时使用本文档,否则走默认书籍模式:

- 期刊/会议论文、预印本(arXiv / bioRxiv / medRxiv 等)的 PDF 或结构化全文;
- 论文 + 补充材料(Supplementary) + 图表/表格附件的组合;
- 论文附带或引用的代码库、数据集、工具等资源锚点。

六阶段骨架、三重验证、晋级门、Capability Bundle 与编译交付全部沿用主流程;
本文档只定义**论文独有的差异**。差异未覆盖处一律回退主流程文档。

## 与书籍模式的差异总表

| 阶段 | 书籍模式 | 论文模式差异 |
|---|---|---|
| 0 | Adler 四步 (整书理解) | 论文结构理解(见下): 贡献解剖 + 可复现资源清单 |
| 0.5 | 语义母本 (01b) | 相同骨架; 差异构件: 图表编号锚点 / 版本锚点 / 贡献→任务映射 (见下) |
| 1 | 5 个提取器 | **5 + 1**: 额外并行激活可复现性提取器 `reproducibility-extractor.md` |
| 1.5 | 三重验证 | 相同; 输出**可验证性分级初判** (reproducible / checkable / subjective) |
| 1.6 | 晋级门 | 相同 (五条独立性判据不变) |
| 2 | RIA++ 能力卡 | E 段参数化强化; `resources` 承载资源锚点; 登记 `verifiability` |
| 3 | Zettelkasten 链接 | 相同; 可选产出论文导航资源 `resources/paper-map.md` |
| 4 | 压力测试 | 断言强度按 verifiability 分级 + 复现/泛化双极查询 + 捷径检测 |
| 5 | 编译交付 | 学术引用规范替代脱敏核查 (见下); 安装验收流程不变 |

## 阶段 0 — 论文结构理解

产出仍写 `books/<slug>/BOOK_OVERVIEW.md`(模板同名),但四步内容按下方重构:

### 步骤 1 — 结构与贡献

- **论文类型**: 方法 / 资源 / 发现 / 综述 / 工具; 目标是"可复用的方法"还是"可引用的结论";
- **核心贡献一句话**: 必须真的能压缩到一句;
- **骨架**: 按 IMRaD(引言-方法-结果-讨论)或论文自有结构列出 3–7 个一级组件及关系;
- **差距**: 论文试图解决的问题与已有工作的差距(Introduction 的逻辑链)。

### 步骤 2 — 方法解剖

- **关键术语**: 论文专属概念与统计口径,按作者用法定义;
- **方法组件链**: 从输入到输出的完整链路(数据 → 处理 → 模型/实验 → 评估);
- **论证链**: 每个组件由哪张图/哪个表/哪段实验支持; 标注支持强度。

### 步骤 3 — 批判与局限 ★ 与书籍模式同等重要

- **作者自述局限**: Limitations / Discussion 节必读,逐条登记;
- **外部效度威胁**: 数据/人群/场景/时间范围限制; 结果可外推到什么范围;
- **未证明假设**: 方法成立依赖但论文未验证的前提;
- **复现障碍**: 数据不公开、算力、专有材料、代码缺失等(与第 6 提取器交叉核对)。

### 步骤 4 — 应用潜力与资源清单

- **可 skill 化清单**: 论文中哪些方法/协议/口径可以独立调用;
- **可复现资源清单**(论文模式标志性产出,写入 overview 独立小节):

```yaml
resource_inventory:
  - name: <资源名>
    kind: code | dataset | tool | model-weights | protocol
    url: <链接>
    license: <许可证; 未声明写 未声明>
    availability: public | on-request | restricted | unavailable
```

- **任务清单**: 以"论文贡献 → 读者可复用任务"映射建立 task_id 清单(替代原书任务清单),
  覆盖方法的每个主要环节; 对原文没有提供的任务条件记缺口,不用常识补成论文的方法。

**质量门**: 贡献一句话可说清; 资源清单逐项标注可得性; 复现障碍显式记录; 骨架展示给用户确认。

## 阶段 0.5 — 论文语义母本（差异）

阶段 0.5 的骨架与流程全部沿用 `01b-stage0.5-semantic-map.md`（产出 `books/<slug>/semantic-map.md`，`mode: paper`）；论文模式在母本上叠加三处差异（01b「论文模式差异」条目的展开）：

1. **图表编号锚点**: `location` 锚定"章节 + 图表编号"（`§5.3` / `Table 1` / `Figure 2（图注）`），不用页码（渲染版本页码不稳定）；引文优先取图注 / 表注 / 正文句，图形内数值循锚点回查原文。
2. **版本锚点**: 母本头部登记所引版本（DOI / arXiv ID + 版本号 + 日期），与「论文模式特有风险 2 — 版本漂移」互锁：替换引用版本必须重跑锚点回查；母本与下游产物一律以登记版本为准。
3. **「贡献 → 任务」映射**: 节点 `task_ids` 承接阶段 0 的"论文贡献 → 读者可复用任务"清单（替代原书任务清单）；映射表与 `resource_inventory` 互联（可复用性受资源可得性约束），随母本一并展示确认。

**质量门（在 01b 五条之上追加）**:

- [ ] 资源清单可得性已登记，映射表与其口径一致；
- [ ] 引用版本在母本头部可见（版本锚点行）；
- [ ] 引文经 `scripts/check_semantic_fidelity.py --source` 机械回查全数命中（多份渲染 / 版本以英文逗号串联传入）。

**示例**: `books/claim-bench-pilot/semantic-map.md` — 三构件齐备 + 缺口如实登记（渲染缺失节以图注为锚、资源链接置空登记、§5.6 正文缺锚路径）。

## 阶段 1 — 5 + 1 提取器

原 5 个提取器照常并行运行; 论文模式**额外并行激活第 6 个**:

| # | extractor | 查找对象 | 产出文件 |
|---|---|---|---|
| 6 | reproducibility-extractor | 实验条件 / 参数 / 协议 / 资源锚点 / 复现障碍 | `candidates/reproducibility.md` |

分工: framework-extractor 找"方法是什么",reproducibility-extractor 找"怎么复现它、缺什么跑不了"。
覆盖率硬门对照阶段 0 的"贡献 → 任务"清单(替代原书任务清单)。

## 阶段 1.5 — 三重验证 + 可验证性分级

三重验证照常执行。论文候选的 V2 演练优先使用论文给出的真实示例数据; 在 V2 记录中补充
**可验证性分级初判**(阶段 2 定稿):

| 等级 | 判据 | 对阶段 4 的含义 |
|---|---|---|
| `reproducible` | 论文附带可执行工件(代码/数据/例题),按其说明可复现出对应数值/图表 | 机械断言必须(数值容差 / 文件存在 / 结构比对) |
| `checkable` | 无论文工件,但有明确数值/图表/清单可逐项核对 | 数值 / 清单核对断言 |
| `subjective` | 纯判断/经验类,无客观对照 | 语义盲评 + 边界用例 |

其余判定与去向(reference / needs_review / rejected)与主流程一致。

## 阶段 2 — 能力卡构造要点

- **E 段参数化强化**: 论文来源的能力卡,执行步骤落到论文给出的具体层面 — 参数、单位、取值范围、
  统计口径、随机种子(如有); 论文未提供的实现约定显式标注为"约定",不改变原意;
- **resources 承载资源锚点**: 数据集/代码/工具以 `resources/paper-map.md`(论文导航: 章节结构、
  图表清单、资源链接与许可证)或能力卡 resources 逐个登记; 只登记链接与说明,不分发受版权保护的
  全文/图表文件;
- **verifiability 登记**: 在 Bundle 能力条目写 `verifiability` 字段(三选一),依据写进 notes;
- **B 段**: 论文局限、外部效度威胁、复现障碍进入 B 段(替代"作者盲点"的常规来源)。

## 阶段 4 — 断言分级与双极查询

- **断言强度按 verifiability**: `reproducible` → 机械数值/文件断言优先且必须;
  `checkable` → 数值/清单核对; `subjective` → 语义盲评为主;
- **双极查询**: 每条 active 能力至少覆盖一类**忠实复现查询**(用论文原始场景/数据)与一类
  **泛化查询**(换新输入/新场景),两侧分别统计通过情况,不以单侧成绩概括整体;
- **捷径检测清单**(照做必查): ① 变化输入是否被真正使用(而非忽略后套用示例结论);
  ② 重复调用的产物是否互相隔离; ③ 是否硬编码论文示例的取值/路径/常量;
  ④ 边界输入是否按 B 段判停处理;
- **回炉预算**: 同一能力回炉上限 2 轮,仍不通过降级 router/参考并记录未解决失败(与主流程一致)。

## 阶段 5 — 引用规范(替代脱敏核查)

论文模式**不执行脱敏清单**,改用学术引用规范:

1. 允许保留论文标题、作者、年份、DOI、期刊与图表编号作为溯源锚点; Bundle `book` 字段可写明;
2. 逐字引文仍遵守 ≤150 字(英文 ≤100 词)限度,不得大段复制正文;
3. 论文全文、补充材料、图表文件不随产物复制分发,以引用编号 + 链接指向原刊/预印本;
4. 交付前复核: 产物中无超出限度的逐字段落、无整图复制;
5. 安装、冒烟验收与收尾汇报流程与书籍模式完全相同(见 `07-stage5-deliver.md`)。

## 论文模式特有风险

1. **版权**: 出版社版本与预印本权利不同; 不确定时只引用、不复制;
2. **版本漂移**: 预印本与发表版可能不同; 记录所引版本(DOI / arXiv ID + 版本号)到 `source_evidence`;
3. **代码不可信**: 论文附带的代码先视为不可信材料,产物不自动执行(与主流程一致);
4. **质量判断不代入引用指标**: 论文的引用数/影响因子不参与候选筛选; 判据只有三重验证与任务增益。
