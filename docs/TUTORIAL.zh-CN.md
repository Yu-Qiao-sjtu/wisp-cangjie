# 上手教程 — 你的第一次蒸馏

> 本教程面向第一次使用 Wisp Cangjie 的用户，带你从零完成一次完整蒸馏。
> 全程约 30–60 分钟（其中大部分时间在等 agent 跑流水线）。
> 语言版本：[简体中文](TUTORIAL.zh-CN.md) · [English](TUTORIAL.en.md)

## 开始之前

1. **一个装好 Wisp 的环境**，且 wisp agent 能读到本 skill（见 README「安装」）。
2. **一份长内容的文字稿**。可以是：书籍的 TXT/EPUB/PDF、视频字幕（srt/ass）、播客转写稿、课程讲义、长文章。Wisp Cangjie 只吃文本——没有文字稿就先用下载/转写工具拿到它，不要让 agent 凭记忆蒸馏。
3. **自检**（可选但推荐）：

```bash
python ~/.wisp/skills/wisp-cangjie/scripts/distill.py doctor
```

看到 `doctor: PASS` 即就绪（`tiktoken`/`jsonschema` 缺失只影响可选功能）。

## 第 1 步 — 触发蒸馏

对 wisp agent 说一句自然的话，例如：

```text
帮我把这本蒸馏成 skill: D:\books\demo-book.txt
```

带上三个信息效果最好：**文本路径**、**书名/作者**（或视频标题/UP 主）、**你的用途**（自己学习查阅，还是接入日常工作流）。

## 第 2 步 — 跟着流水线走（你要做什么）

流水线共六个阶段，你只在三个确认门需要表态，其余时间等它跑：

| 阶段 | 发生了什么 | 你要做什么 |
| --- | --- | --- |
| 0 整书理解 | agent 通读全文，产出骨架/术语/批判（BOOK_OVERVIEW.md） | **确认门 ①**：骨架对不对？有没有想重点突出的方向？ |
| 1 并行提取 | 5 个提取器分别扫全书，产出候选方法论池 | 等待 |
| 1.5 三重验证 | 每个候选过三关：来源充分 / 可执行 / 有任务增益 | **确认门 ②**：看入选名单，不同意就指出 |
| 1.6 晋级门 | 评选哪些能力够格做独立 skill，其余保留为能力卡 | 等待 |
| 2–3 能力卡+链接 | 每个通过的能力写成 R/I/A1/A2/E/B 卡片并互相关联 | 等待 |
| 4 压力测试 | 盲测触发精度（含"不该触发"的诱饵题）+ 实际完成任务 | 等待；不通过的会自动回炉 |
| 5 编译交付 | 编译成 single 或 pack，生成精华长文 DIGEST.md | **确认门 ③**：输出模式按推荐/改 single/改 pack；选择安装位置 |

两点提醒：**先试点**——第一次用拿一份小内容跑通流程，再批量；**断点续跑**——中途中断没关系，重新说一句"继续蒸馏"即可，进度记录在 `books/<slug>/PIPELINE_STATE.md`。

## 第 3 步 — 认识产物

跑完后，工作目录下会有：

```text
books/<slug>/
├── DIGEST.md            ← 先看这个：面向人的精华长文
├── GLOSSARY.md          ← 全书术语词典
├── coverage-audit.md    ← 哪些任务覆盖了、哪些没有（如实登记）
└── dist/<...>/          ← 编译好的 skill 包（这才是要安装的东西）
```

编译产物是一个标准 skill 包：入口 `SKILL.md`（触发条件+路由表）+ `references/capabilities/`（能力卡）+ `references/overview.md|glossary.md|cheatsheet.md`。日常使用入口 SKILL.md 即可；想深究某个能力，按路由表去读对应能力卡。

注意：**交付物已脱敏**——源文档的书名、作者、章节标题、逐字引文不会出现在安装的 skill 里，完整溯源只保留在本机 `books/<slug>/` 审计轨迹中。

## 第 4 步 — 安装

编译产物复制到 wisp 用户级技能目录：

```bash
cp -r books/<slug>/dist/<入口名> ~/.wisp/skills/
```

重启/刷新 wisp 运行时，用一句"should trigger"的话术试一下（比如蒸馏的是决策方法，就问一个纠结的决策问题），确认能触发。同一个内容**不要同时安装 single 和 pack 两套**，二选一。

## 日常维护

- **修订后防退化**：蒸馏产物的 `test-prompts.json` 是回归评测集。改过 skill 后重跑：
  `python scripts/distill.py eval trigger ...`（触发评测）或 `eval output ...`（输出评测）。
- **内容更新了**：把新增材料喂给 `python scripts/distill.py update --pack <目录> --add <新文件>`，它会做差异分析并生成待处理任务，不会静默改产物。
- **改坏了**：`python scripts/distill.py rollback --pack <目录> --list` 查看快照并回滚。
- **本地改了产物**：编译器检测到手工修改会拒绝静默覆盖——三选一：`--force-overwrite` 丢弃修改 / 把修改回填 Bundle 重编译 / 中止。

## 常见问题

- **视频没有字幕怎么办？** 先用下载/转写工具拿到文字稿再触发；agent 遇到无文本的情况会停下来向你要，不会凭记忆硬拆。
- **什么样的内容适合蒸馏？** 有可提取方法论的：方法论书、教程课、访谈、经验分享。纯叙事/娱乐内容会被三重验证筛掉大部分。
- **产物里会暴露我用的原书吗？** 不会，交付物强制脱敏（见上）；完整溯源只在你本机的审计轨迹里。
- **一次能蒸几本？** 技术上无限制，但先试点 1 份、确认产出质量符合预期后再批量。
- **编译报"检测到本地手工修改"？** 见"日常维护"最后一条的三选一。
